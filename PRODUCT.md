# Pokémon Battle Simulator — presentation deck

A single-file HTML slide deck (index.html + styles.css + deck.js, no build step) for the
CSC207 final presentation of the Pokémon Battler project. Presented from a laptop onto a
projector; also readable on a laptop and printable.

- **Register:** brand — the deck's design mirrors the product's own identity.
- **Visual identity:** the retro GBA look of the app itself (`../pokemon-battler/frontend`):
  Press Start 2P pixel type, cream `#f8f0d8` dialog panels, chunky brown `#5a4a3a` squared
  borders with inset lit highlights, hard offset shadows with no blur, GBA blue `#4878d0`,
  official Pokémon type colours, `steps()` transitions.
- **Constraints:** offline-safe (fonts bundled in `assets/fonts/`), dense technical content
  (code blocks, tables, class diagrams) must stay legible from the back of a room, so body
  copy uses IBM Plex Sans and code uses JetBrains Mono; the pixel font carries headings,
  labels and chrome.
- **Audience:** course instructors and TAs grading against a rubric; the team presenting.
